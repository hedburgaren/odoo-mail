Unified Workspace

Extend Discuss into a communication hub

Brings personal email, calendar, chat and tasks into one place. Reuses existing Odoo mail, CRM, calendar and project infrastructure.

Features

  • Personal email inbox per user (IMAP routing)
  • Folder structure: Inbox, Sent, Drafts, Trash and custom folders
  • Conversation threads
  • Full composer with CC/BCC and signatures
  • One-click CRM actions from any email
  • Contact card in the reading pane
  • Calendar and chat reachable from the same sidebar
